# React Learning Journey

This repository documents my journey of learning modern React development using **React** and **Vite**.

The repository contains hands-on exercises, reusable components, form validation practice, state-management exercises, and mini projects built while learning React.

The goal is to understand React fundamentals by **learning → practicing → building → reviewing**.
